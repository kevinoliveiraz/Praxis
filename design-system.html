Regra de contraste

Use texto escuro sobre verde-lima e superfícies claras. Em fundo escuro, use Paper para títulos e Muted para textos de apoio. Nunca use verde-lima como texto sobre branco.

07 / IMPLEMENTAÇÃO

Uma base única para cada página.

Carregue os tokens antes dos componentes e deixe o CSS de composição por último. As páginas existentes também recebem os tokens compartilhados.

<link rel="stylesheet" href="styles/tokens.css">
<link rel="stylesheet" href="styles/components.css">
<link rel="stylesheet" href="styles/sua-pagina.css">
Separação de responsabilidades

tokens.css define os fundamentos; components.css define componentes com prefixo px; o CSS da página organiza o layout. A configuração provisória dos planos fica em scripts/planos.js.
